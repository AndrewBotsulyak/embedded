# Домашнее задание 2.4 — ESP-IDF

Проект собран на **ESP-IDF** (target ESP32-S3).

## Что делает

При нажатии на кнопку запускается мигание светодиода. Кнопка обрабатывается через прерывание по GPIO, нажатие фильтруется от дребезга контактов.

| Назначение | Пин     |
| ---------- | ------- |
| Кнопка     | GPIO 17 |
| Светодиод  | GPIO 10 |

## Структура

- [main/main.c](main/main.c) — точка входа, инициализация и главный цикл
- [main/isr-button/](main/isr-button/) — настройка GPIO кнопки, обработчик прерывания, устранение дребезга
- [main/blink/](main/blink/) — управление светодиодом

## Сборка и прошивка

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

## Что освоил

- **GPIO**: `gpio_config()`, режимы входа и выхода, подтяжка `pull_up_en`, чтение уровня через `gpio_get_level()`
- **Прерывания**: `gpio_install_isr_service()`, `gpio_isr_handler_add()`, выбор фронта через `intr_type`, размещение обработчика в IRAM с помощью `IRAM_ATTR`, передача пользовательских данных в ISR
- **`vTaskDelay()`** и `pdMS_TO_TICKS()`: зачем задача обязана отдавать процессор, как это связано с task watchdog, и чем блокирующая пауза отличается от неблокирующей проверки времени по `esp_timer_get_time()`
