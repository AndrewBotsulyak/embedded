# home_work_2_5-timers

Простой blink-проект на ESP-IDF: светодиод мигает не по `vTaskDelay`, а по прерыванию
аппаратного таймера общего назначения (GPTimer).

## Как это работает

- `setup_led()` — настраивает GPIO 10 на выход и выставляет начальное состояние.
- `setup_timer()` — создаёт таймер GPTimer с разрешением 1 МГц (1 тик = 1 мкс),
  регистрирует колбэк на событие alarm и запускает таймер.
- Alarm настроен на `500 000` тиков (= 500 мс) с автоперезагрузкой счётчика в 0,
  поэтому прерывание срабатывает каждые полсекунды.
- `on_timer_alarm()` — ISR-колбэк (в `IRAM_ATTR`): инвертирует `led_state`,
  пишет его в GPIO и инкрементирует `counter`.
- `app_main()` после инициализации просто раз в 500 мс логирует текущие значения
  `counter` и `led_state` — вся работа с светодиодом идёт из прерывания.

## Параметры

Задаются макросами в [main/main.c](main/main.c):

| Макрос | Значение | Назначение |
| --- | --- | --- |
| `LED_PIN` | `GPIO_NUM_10` | пин светодиода |
| `RESOULUTION_HZ` | `1000000` | разрешение таймера, тиков в секунду |
| `ALARM_TRESHOLD` | `500000` | порог alarm в тиках (500 мс) |

## Целевая платформа

ESP32-S3 (`CONFIG_IDF_TARGET="esp32s3"`). В репозитории есть devcontainer
[.devcontainer/](.devcontainer/) с ESP-IDF и QEMU, так что проект можно собирать
и запускать без железа.

## Сборка и запуск

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

В мониторе видно растущий счётчик срабатываний таймера:

```
I (xxx) timer: counter = 1, led_state = 1
I (xxx) timer: counter = 2, led_state = 0
```
