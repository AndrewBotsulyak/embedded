# ДЗ 3.1 — Калибровка АЦП (ESP32-S3)

## Задание

1. Подключить потенциометр (~10 кОм) в виде делителя напряжения.
2. Учесть опорное напряжение, аттенюацию и разрядность АЦП (их можно вывести в таблицу для информации).
3. Настроить АЦП и считывать значения каждые ~100 мс.
4. Сделать несколько измерений. Для каждого измерения:
   - считать RAW-значение АЦП и вычислить напряжение по формуле;
   - считать напряжение с помощью калиброванного АЦП;
   - вычислить погрешность (%) между вычисленным и калиброванным напряжением.
5. Вывести в серийную консоль таблицу вида:

```
RAW   U_manual(mV)   U_cali(mV)   Error(%)
```

## Схема

- Потенциометр 10 кОм включён делителем: верхний вывод — на `GPIO4` (программно выставлен в `1`, играет роль питания делителя), нижний — на `GND`, средний — на вход АЦП `GPIO7`.
- `GPIO7` на ESP32-S3 — это `ADC1_CH6`.

## Параметры измерения

| Параметр | Значение |
|---|---|
| АЦП / канал | ADC1, `ADC_CHANNEL_6` (GPIO7) |
| Разрядность | 12 бит → RAW = 0…4095 |
| Аттенюация | 12 дБ (`ADC_ATTEN_DB_12`), диапазон ~0…3.1 В |
| Опорное напряжение для ручного расчёта | 3300 мВ (номинальное питание платы) |
| Схема калибровки | Curve Fitting (`adc_cali_create_scheme_curve_fitting`) |
| Период опроса | 100 мс (`ADC_READ_DELAY`) |
| Реальное «калибровочное» напряжение | **3152 мВ** (значение `U_cali` при RAW = 4095) |

## Что сделано

- Настроен одноразовый (oneshot) режим АЦП: `adc_oneshot_new_unit` + `adc_oneshot_config_channel` с разрядностью 12 бит и аттенюацией 12 дБ.
- Создана схема калибровки Curve Fitting — она использует заводские коэффициенты, зашитые в eFuse конкретного чипа.
- Ручной расчёт напряжения по линейной формуле:

  ```
  U_manual = RAW / 4095 * 3300 мВ
  ```

  реализован в `get_adc_voltage_mv()` ([main/main.c](main/main.c)).
- Калиброванное напряжение получено через `adc_cali_raw_to_voltage()`.
- Погрешность считается относительно калиброванного значения (оно принято за эталон) в `get_error_percent()`:

  ```
  Error = |U_manual − U_cali| / U_cali * 100 %
  ```

- Каждые 100 мс в консоль печатается строка таблицы (`printf` с выравниванием по колонкам), шапка выводится один раз при старте.

## Пример вывода

```
RAW    U_manual(mV)   U_cali(mV)   Error(%)
512    412.6          394          4.72
1024   825.2          788          4.72
2048   1650.4         1576         4.72
3072   2475.7         2365         4.68
4095   3300.0         3152         4.70
```

## Выводы

- Ручной расчёт систематически **завышает** напряжение примерно на **4.7 %** во всём диапазоне. Это прямое следствие того, что реальная верхняя граница шкалы не 3300 мВ, а 3152 мВ: `3300 / 3152 ≈ 1.047`.
- Погрешность почти не зависит от RAW, то есть это не случайный шум, а масштабный (мультипликативный) сдвиг — ошибка в предположении об опорном напряжении, а не в самих отсчётах АЦП.
- Формула `RAW / 4095 * VREF` предполагает идеально линейный АЦП с точно известным опорным напряжением. На практике ни то, ни другое не выполняется: реальное опорное напряжение отличается от номинала, а характеристика АЦП ESP32 нелинейна, особенно на краях диапазона (у нуля и у насыщения).
- Калибровочные коэффициенты индивидуальны для каждого чипа (зашиты в eFuse), поэтому «подогнать» константу 3300 → 3152 и использовать её на всех платах нельзя — на другом экземпляре коэффициент будет свой.
- Практический вывод: для любых измерений, где важна абсолютная точность, нужно использовать `adc_cali_raw_to_voltage()`. Ручной пересчёт годится только там, где нужна относительная величина (положение потенциометра, «больше/меньше», пороги), а не реальные вольты.
- Даже с калибровкой у аттенюации 12 дБ линейный участок ограничен примерно 0…3.1 В, поэтому вблизи верхней границы значения «упираются» в потолок и точность падает — измерять лучше в середине диапазона.
