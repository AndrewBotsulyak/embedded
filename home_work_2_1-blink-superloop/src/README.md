# Blink Superloop (2.1)

Управление яркостью и режимами работы светодиода двумя кнопками с автоматической
регулировкой по датчику освещённости (фоторезистору).

## Схема подключения

| Элемент                    | Пин       | Примечание                                        |
|----------------------------|-----------|---------------------------------------------------|
| Светодиод + резистор 220 Ом | 11 (`LED_PIN`) | ШИМ-выход, управление яркостью                |
| Фоторезистор + резистор 1000 Ом (делитель напряжения) | 7 (`LDR_PIN`) | Пин запитывает делитель (`HIGH`)             |
| Аналоговый вход (ADC)      | 5 (`ADC_PIN`)  | Считывает напряжение с фоторезистора          |
| Левая кнопка               | 8 (`LEFT_BTN`) | Увеличение яркости / смена режима             |
| Правая кнопка              | 18 (`RIGHT_BTN`)| Уменьшение яркости / смена режима            |

### Светодиод
Светодиод подключён к пину **11** через токоограничивающий резистор **220 Ом**.
Яркость задаётся через ШИМ (LEDC, разрешение 12 бит → 0..4095).

### Фоторезистор
Фоторезистор с последовательным резистором **1000 Ом** образует делитель напряжения.
Пин **7** подаёт питание на делитель (`digitalWrite(LDR_PIN, HIGH)`), а аналоговый
вход **5** считывает напряжение в средней точке делителя (`analogRead(ADC_PIN)`).
Чем больше освещённость, тем сильнее меняется сопротивление фоторезистора и, как
следствие, считываемое значение.

## Логика управления

Программа построена по принципу **superloop**: в `loop()` последовательно
опрашиваются кнопки, обрабатывается текущий режим светодиода и логика кнопок.

### Кнопки
- **Левая кнопка** — по нажатию увеличивает яркость на **10%**.
- **Правая кнопка** — по нажатию уменьшает яркость на **10%**.
- **Обе кнопки одновременно** — переключают режим работы светодиода.
  Режим можно переключать, **не отпуская одну из кнопок**: пока одна кнопка
  удерживается, каждое нажатие второй переключает режим на следующий.
  Пока идёт переключение режимов, обычная регулировка яркости заблокирована
  (флаг `isModeEditing`), чтобы одиночные нажатия не меняли яркость.

Кнопки обрабатываются через прерывания (`onChange` / ISR) с программным
антидребезгом (`DEBOUNCE_DELAY = 20 мс`).

### Режимы работы светодиода
Всего **3 режима**, переключаются по кругу (`nextMode`):

1. **LDR** — автоматическая регулировка яркости по фоторезистору.
   Значение с ADC сравнивается с порогами (`adcDutyTreshold`, `minDutyTreshold`),
   и яркость подстраивается под уровень освещённости.
2. **CONSTANT_LIGHT** — постоянное свечение с яркостью, заданной кнопками
   (шаг регулировки `ledLightStep` = 10% от диапазона).
3. **BLINK** — мигание с периодом `BLINK_DELAY = 500 мс`.

## Структура проекта

```
src/
├── main.cpp          # superloop: setup() и loop()
├── config/config.h   # пины и константы (яркость, пороги, задержки)
├── led/              # LedADC: ШИМ, режимы, яркость, мигание, LDR
├── button/           # Button: опрос кнопок, антидребезг, прерывания
└── control/          # AppControl: связывает кнопки и логику светодиода
```
